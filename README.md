# Adrian_Gonzalez_Barquin_TFG
Aplicación web para generar planes de cultivo óptimos a partir de la información geográfica de las
parcelas de una explotación y de sus restricciones operativas y normativas. Incluirá una interfaz
cartográfica y permitirá calcular, comparar y exportar planes, así como comprobar su viabilidad
ante cambios en los recursos y las restricciones.
